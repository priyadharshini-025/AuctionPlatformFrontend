# Auction Platform - Frontend

A modern React.js frontend for a full-stack Auction Platform where users can browse items, place bids, and sellers can manage auctions.

## Live Features
# User
 * Register & Login
 * Browse auctions with filters
 * View item details
 * Place bids (Normal / Sealed / Reverse)
 * View bid history
 * Get notified when outbid

# Seller
 * Add & manage products
 * Create auctions
 * Track auction status (Active / Ended / Sold / Unsold)
 * Inventory management


## Tech Stack
 * React.js 18
 * Tailwind CSS
 * React Router DOM
 * Axios
 * Context API

## UI Highlights
 * Clean card-based auction layout
 * Responsive design using Tailwind
 * Hover animations and transitions
 * Real-time auction updates
